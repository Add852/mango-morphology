# Monocular Depth-Assisted Morphological Properties Estimation of Mangoes

This repository contains the source code, dataset labels, custom packages, trained machine learning models, and a FastAPI web dashboard used for the research and development of estimating the morphological and biological properties (size, weight, orientation, and ripeness) of Indian mangoes. The system combines **YOLOv11n** (for instance segmentation) and **DepthAnythingV2** (for monocular depth estimation) with a multi-layer regressor pipeline.

---

## Dual Pipeline Design

The system implements two distinct pipelines for physical properties estimation:

1. **ArUco-Calibrated Pipeline:**
   - Detects a 6x6 ArUco marker (ID 0, standardized to 5.0 cm printed size) in the frame.
   - Calibrates pixel-to-metric scale factor (`aruco_scale`) and camera-to-mango distance using the marker's known physical dimensions.
   - Ideal for scenarios requiring high-precision physical scaling.

2. **Raw Monocular Depth (Non-ArUco) Pipeline:**
   - Operates purely on raw metric depth estimates generated by DepthAnythingV2.
   - Useful for marker-free field capture and mobile dashboard deployment.
   - Automatically selected as a fallback if no ArUco marker is detected in the image.

---

## Multi-Layer Modeling Structure

To estimate external and internal properties accurately, features are passed through a sequential prediction pipeline:

1. **Feature Extraction:** 
   - YOLOv11n extracts the 2D segmentation mask and bounding box.
   - DepthAnythingV2 generates a dense depth map.
   - 3D coordinates are back-projected to construct a spatial point cloud from which geometric, curvature, color (CIELab/HSV), contour roundness, and depth distribution statistics are extracted.
2. **Orientation Classification:**
   - A Random Forest classifier determines the spatial alignment of the mango from one of five orientations (`side`, `top`, `bottom`, `front`, `back`).
3. **Layer 1: External Morphology & Ripeness:**
   - Specialized Random Forest regressors and classifiers for the predicted orientation estimate the external dimensions: **Height (cm)**, **Width (cm)**, **Thickness (cm)**, **Volume ($cm^3$)**, and **Weight (g)**, and determine the ripeness state (**Ripe** vs **Unripe**).
4. **Layer 2: Internal Seed (Endocarp) Morphology:**
   - Predicts internal seed parameters (**Height**, **Width**, **Thickness**, **Volume**, and **Weight**) using predictions from Layer 1 combined with the ripeness label.

## Repository Structure

- **`app/`**: FastAPI backend and interactive web dashboard.
  - [`main.py`](app/main.py): REST API endpoints and dashboard controller.
  - [`inference.py`](app/inference.py): Runtime wrapper managing model loading, image pre-processing/decoding, and multi-layer predictions.
  - [`packing.py`](app/packing.py): 3D container packing simulation estimating container capacity and simulating 3D placement coordinates (with Hexagonal Close-Packing).
  - [`requirements.txt`](app/requirements.txt): Python dependencies specific to the FastAPI dashboard server.
  - [`test_api.py`](app/test_api.py): Integration test suite.
  - `templates/`: Contains `index.html`, the frontend dashboard displaying 3D packing overlays with Three.js.
- **`models/`**: Serialized Random Forest model weights, YOLO segmentation weights, and metric depth checkpoints.
  - `DepthAnythingV2/`: Monocular depth checkpoints.
  - `YoloV11n/`: YOLO nano instance segmentation weights.
  - `aruco/`: Classifiers and regressors trained on ArUco-calibrated metric features.
  - `aruco_no/`: Models trained on uncalibrated monocular depth features.
- **`packages/`**: Embedded vendorized dependencies.
  - `depth_anything_v2/`: Core network architecture.
  - `depth_anything_v2_metric/`: DepthAnythingV2 wrappers for metric estimation.
- **`labels/`**: Segmentations, annotations, and CSV databases of extracted physical properties.
- **`images/`**: Dataset partition folders containing train/val/test images (663 images, ~1 GB — hosted on HuggingFace, see [Model Weights & Dataset](#model-weights--dataset)).
- **`manuscript/`**: LaTeX source and compiled PDF of the paper.
- **`notebook_aruco.ipynb`**: Interactive notebook demonstrating ArUco-calibrated model training and validation workflows.
- **`notebook_noruco.ipynb`**: Interactive notebook demonstrating model training workflows on raw depth maps.
- **`group_feature_search.py`**: Feature selection tool performing greedy forward feature selection and backward pruning via GroupKFold cross-validation grouped by `mango_id`.

## Model Weights & Dataset

Large binaries are not stored in git. Download them as follows:

### DepthAnythingV2 checkpoints (~95 MB each)

```bash
mkdir -p models/DepthAnythingV2
wget -P models/DepthAnythingV2 https://huggingface.co/depth-anything/Depth-Anything-V2-Small/resolve/main/depth_anything_v2_vits.pth
wget -P models/DepthAnythingV2 https://huggingface.co/depth-anything/Depth-Anything-V2-Metric-VKITTI-Small/resolve/main/depth_anything_v2_metric_vkitti_vits.pth
wget -P models/DepthAnythingV2 https://huggingface.co/depth-anything/Depth-Anything-V2-Metric-Hypersim-Small/resolve/main/depth_anything_v2_metric_hypersim_vits.pth
```

### YOLOv11n base weights

`yolo11n-seg.pt` downloads automatically on first use via the Ultralytics package. Manual download: [Ultralytics assets release](https://github.com/ultralytics/assets/releases/download/v8.3.0/yolo11n-seg.pt) → place in `models/YoloV11n/`.

### Dataset images (~1 GB)

The train/val/test image dataset is hosted on HuggingFace Datasets: [Add852/mango-morphology-images](https://huggingface.co/datasets/Add852/mango-morphology-images). Download with one line:

```python
from huggingface_hub import snapshot_download
snapshot_download(repo_id="Add852/mango-morphology-images", repo_type="dataset", local_dir="images")
```

### Trained model artifacts (included in this repository)

- `models/YoloV11n/runs/segment/mango_seg_v1-4/weights/best.pt` — final YOLO segmentation weights used by the app
- `models/orientation/orientation_cnn.pth` — orientation CNN weights
- `models/aruco/`, `models/aruco_no/` — trained Random Forest regressors/classifiers for both pipelines

## Execution Guide

### 1. Running the FastAPI Web Dashboard
To launch the FastAPI server locally:

```bash
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Once running, navigate to `http://localhost:8000` in your web browser to access the dashboard. Here, you can:
- Upload images to see live segmentations, orientation classification, and physical dimension predictions.
- Simulate the number of estimated mangoes that can fit inside standard (shipping box, crate, basket) or custom dimensions with 3D renderings.

### 2. Running API Integration Tests
To verify server endpoints (health-check, prediction pipelines):

```bash
python app/test_api.py
```

### 3. Feature Selection & Evaluation
To run the automated feature selection and evaluation script:

```bash
python group_feature_search.py
```
